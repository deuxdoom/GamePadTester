지금 이 브라우저에서 패드를 시험해 보세요

패드를 연결하고 아무 버튼이나 누르면 앱과 같은 그림으로 입력을 보여 줍니다. 이미 연결된 패드는 페이지를 연 뒤 버튼을 한 번 누르면 바로 인식됩니다. 스틱 원형도도 앱처럼 10초 동안 잴 수 있습니다.

패드의 아무 버튼이나 눌러 주세요 · 이미 연결된 패드도 버튼을 눌러야 인식됩니다

스틱 원형도

측정을 누르고 두 스틱을 가장자리에 붙인 채 돌리세요. 가장자리에 닿은 뒤 10초면 끝납니다.

이 브라우저가 패드를 읽는 빈도

– Hz

브라우저는 화면 주사율에 묶여 있어서 진짜 폴링레이트를 잴 수 없습니다. 앱은 C++ 엔진이 보고서가 도착한 시각을 그대로 기록해 8,000 Hz까지 잽니다.

이 브라우저는 Gamepad API를 지원하지 않습니다. 최신 Chrome, Edge, Firefox에서 열어 보세요.

기능

패드 점검에 필요한 것을 한 프로그램에

스틱 원형도

gamepad-tester.com과 같은 방식으로 32개 방향(11.25°)마다 가장 멀리 닿은 거리를 기록해 RMS 평균 오차와 등급을 냅니다. 가장자리에 닿은 뒤 10초면 끝나고, 결과는 32구간 쐐기로 그려 기준 원에서 벗어난 방향일수록 빨갛게 표시합니다. 드리프트·해상도·스냅백도 잽니다.

폴링레이트

XInput 패킷, HID 원시 보고서, SDL 보고서 중 하나로 잽니다. 통계는 Gamepadla와 같은 방식이고 소수점까지 보여 주며, 중앙값·최대/최소 간격·안정도·이상치도 냅니다. 8 kHz 패드도 정확합니다. 개요 화면에서는 스틱을 돌리기만 해도 대략적인 값이 보입니다.

결과 카드

원형도·드리프트·폴링 결과를 설정에서 고른 폴더에 800×400 이미지로 바로 저장합니다. 드리프트 카드는 두 스틱의 중심 오차·흔들림·최대 편차·평균 AXIS 0~3 값을 담습니다. 폴링 수치는 천 단위 쉼표 없이 소수점만 표시합니다.

원시 스틱 진단

스틱 진단은 원시 값으로 내장 데드존과 축 스냅핑을 찾습니다. XInput·SDL 폴링만 중심 5%의 변화를 제외하며, HID 직접 측정은 보고서 도착 간격을 잽니다.

패드 4개까지

실제 장치명이 보이는 탭으로 바꿔 보고, 패드 이름을 직접 붙일 수 있습니다. 측정은 패드마다 따로 진행합니다.

패드에 맞춘 화면

Xbox Series, DualSense, ProCon 2의 실제 사진에서 딴 윤곽과 버튼 배치로 그립니다. 닌텐도식 ABXY와 후면 버튼도 보여 줍니다.

Gamepadla 비교

패드의 실측 지연 데이터를 찾아 내 폴링 결과와 비교합니다. 읽기만 하고 아무것도 올리지 않습니다.

DualSense USB OverClock

Gamepadla에서 Verified로 확인된 일반 USB DualSense의 이름 옆 빨간색 OverClock 버튼을 누르면 1000Hz를 적용하고, 다시 누르면 원래 설정으로 복원합니다. 적용 상태는 OverClock ON으로 표시하며, 옆 정보 버튼에서 실제 HID 보고율을 확인합니다. 관리자 승인 후 해당 장치만 자동 재연결합니다. DualSense Edge는 기본 1000Hz라 대상이 아닙니다.

버튼·트리거

누른 횟수·시간·간격을 세고 채터링을 찾아냅니다. 트리거는 정지값·최대값·해상도를 봅니다.

진동·라이트

좌우 모터와 9가지 패턴, Xbox 트리거 진동, DualSense 적응형 트리거, DualSense LED 색.

모션·터치

자이로·가속도 그래프와 보고율, 정지 캘리브레이션, 3D 자세, 터치패드 손가락 위치.

조합 입력

최대 동시 누름과 상하·좌우 동시 입력 횟수를 기록합니다. 입력값은 바꾸지 않습니다.

6개 언어·두 가지 테마

6개 언어, 다크테마·라이트테마와 강조색. 기본값은 시스템 테마로 Windows의 앱 모드 설정을 따릅니다. 고정 창이 Windows 배율에 맞춰 주 모니터 중앙의 개요 화면에서 시작합니다.

설치 없는 포터블

압축을 풀고 실행하세요. 설정·캐시는 앱 옆에, 텍스트 리포트는 report/에 저장합니다. 이미지 폴더는 설정에서 고릅니다.

화면

한 화면에 필요한 것만

모든 페이지가 스크롤 없이 한 화면에 들어갑니다. 그림을 누르면 크게 볼 수 있습니다.

자동 업데이트

새 버전은 버튼 한 번으로,
받은 파일은 SHA-256으로 확인합니다

전체 릴리스 내역부터 설치와 재실행까지, 독립된 창 하나에서 확인합니다. 다운로드 속도와 처리한 파일 수를 단계별로 보여 줍니다.

실제 독립 업데이트 창의 캡처입니다. 버전과 릴리스 내역은 예시입니다.

정확하게 재는 방법

세 가지만 기억하세요

1

원형도

스틱 화면에서 측정을 누르고 스틱을 가장자리에 붙인 채 돌립니다. 닿은 뒤 10초 동안 두세 바퀴 이상 돌리면 됩니다.

2

폴링레이트

USB 허브 없이 PC에 바로 연결하고, 측정이 끝날 때까지 스틱을 빠르게 원을 그리며 돌립니다.

3

모션 센서

모션 센서를 지원하는 패드를 평평한 곳에 놓고 정지 보정을 누릅니다. 3초 동안 움직이지 않은 뒤, 기울이거나 돌려 자이로·가속도 반응을 확인합니다.

자주 묻는 질문

궁금한 점

'Windows의 PC 보호' 창이 떠요.

코드 서명을 하지 않은 프로그램이라 처음 한 번 나타날 수 있습니다. 추가 정보를 누른 뒤 실행을 누르세요.

어떤 패드를 쓸 수 있나요?

XInput 패드(Xbox와 호환 패드), DualSense·DUALSHOCK 4, Switch Pro·ProCon 2 컨트롤러 등 SDL 3이 지원하는 패드를 모두 인식합니다. ProCon 2는 USB 케이블로 연결하면 앱이 PC 모드로 자동 전환합니다(블루투스 미지원).

측정 결과가 어딘가로 전송되나요?

아니요. 결과는 내 PC에만 저장됩니다. 인터넷은 Gamepadla 조회와 업데이트 확인에만 씁니다.

2.x에서 자동으로 업데이트되나요?

v3는 새로 만든 버전이라 자동으로 넘어가지 않습니다. ZIP을 새 폴더에 풀어서 쓰세요. 다음 버전부터는 자동 업데이트가 됩니다.

웹 체험판과 앱은 무엇이 다른가요?

브라우저는 화면 주사율만큼만 패드를 읽어서 폴링레이트를 잴 수 없습니다. 앱은 C++ 엔진이 보고서를 직접 읽고, 진동·자이로·Gamepadla 비교 같은 기능도 씁니다.

설정은 어디에 저장되나요?

프로그램 폴더의 settings.json에 저장됩니다. 폴더째로 옮겨도 설정이 따라갑니다.
